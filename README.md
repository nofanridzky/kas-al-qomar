# Kas Musholla Al Qomar

Laporan keuangan Musholla Al Qomar Dps (Denpasar, Bali) untuk jamaah.

- Web app statis (HTML, CSS, JavaScript tanpa build), dipasang lewat GitHub Pages.
- Data dibaca dari Google Sheets milik pengurus melalui Google Apps Script (`apiUrl` di `config.js`). Sheets tetap privat.
- Pengurus mencatat dan memeriksa transaksi lewat halaman pengurus (`pengurusUrl`).

Pengaturan hanya ada di `config.js`.
